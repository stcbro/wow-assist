# WowAssist · 简单好用又省心的香草旧世魔兽游戏助手

为**水豚乐园**（apac.capycraft.io）玩家打造的一站式客户端助手：模组、插件、字体的下载、安装、管理，以及启动游戏，全部在一个界面完成。**双击即用，无需安装任何环境。**

> 原创自研作品，仅供玩家免费学习交流，请勿倒卖、冒充官方或用于商业用途。

---

## ✨ 功能特性

- **📦 一站式配置**：「配置组件」自动完成 资源下载 → 模组安装 → 插件安装 → 字体安装，全部就绪后才能启动游戏，杜绝装一半就进游戏的问题
- **🧩 模组**：内置注入器在游戏启动极早期自动加载核心模组 DLL（游戏目录无需额外加载器）；模组勾选管理，写入 dlls.txt 全自动
- **📦 插件**：150 个插件勾选管理（支持搜索 + 分类/状态筛选）；库插件与客户端前置锁定必选
- **🔤 字体**：思源黑体（Noto Sans SC，SIL OFL 开源可商用）一键装入，含伤害数字槽位
- **⬇️ 下载**：蓝奏云文件夹自动解析，多分卷按序下载解压；支持自定义直链源（COS/OSS/GitHub）；缓存 30 天未用自动清理
- **🔄 自动更新**：程序启动后台检查新版本，发现更新一键升级（自动下载 → md5 校验 → 替换重启）
- **🛡️ 幂等与安全**：已下载不重下、已安装跳过；安装前原有文件先备份（WowAbak）；「清理还原」一键恢复客户端初始状态
- **🖥️ 桌面体验**：单窗口 980×680，最小化收托盘，高 DPI 适配，游戏启动不卡界面

## 🚀 快速上手

1. 双击 `wowassist.exe`
2. 首页确认游戏路径（不在游戏根时点「设置」选择 WoW.exe）
3. 点「🔧 配置组件」→ 等待 资源/模组/插件/字体 全部 ✓
4. 点「▶ 启动游戏」，登录界面输入账号密码（勾选客户端自带「记住帐号名」）
5. 想恢复干净客户端？点「⏻ 清理还原」

## 🛠️ 技术栈

Python（bottle + pywebview）+ 单页 HTML UI，PyInstaller 打包为单文件 exe；模组加载采用运行时注入；分发基于蓝奏云文件夹直链解析（含反爬适配）。
