## 三项修复（22:38 版）
- **① 双击 exe 黑窗一闪而过**：根因是 `_ensure_hidden_console()` 调了 `AllocConsole()`——它会先弹【可见黑窗】再 `ShowWindow(SW_HIDE)` 隐藏，那一帧就是用户看到的黑窗。该函数的本意（给子进程一个隐藏控制台避免它们各自弹窗）已被 `_run_hidden/_popen_hidden`(CREATE_NO_WINDOW) 覆盖，故直接清空函数体。另补两处曾绕过隐藏封装的子进程：`/api/open` 的 `explorer /select` 由 `shell=True`(会闪 cmd) 改为列表直启 `["explorer","/select,"+sel]`；`_game_running` 的 `tasklist` 由裸 `subprocess.run` 改为 `_run_hidden`（游戏启动/taskkill 早已走隐藏封装）。从此任何来源的控制台窗口都不会弹出。
- **② 更新日志 v2.9-v3.7 字体颜色/大小不一致**：源码里 v1.x~v3.7 其实都已统一成同一内联样式，用户看到的差异是**部署的 exe 仍是旧 ui.html**（样式统一那版没重新打包部署）。本次把明细样式抽成统一 CSS 类 `.cl-detail{padding:8px 0;color:var(--sub);font-size:13px;line-height:1.7}`，19 条明细 div 全改 `class="cl-detail"`，从根上锁死一致、杜绝后续编辑漂移。
- **③ 托盘图标鼠标一过去就消失**：两个根因叠加——(a) 旧 ICO 全部是非正方形尺寸（256×241 等，转 ICO 时按原图比例缩放没补成正方形），Windows 通知区图标必须正方形，非方形在悬停重绘时会被丢弃。已用 PIL 把图居中贴进透明正方形画布，重生成标准正方形多尺寸 ICO(16~256)；(b) 托盘线程**在线程启动后才 `SetApartmentState(STA)`**，必抛 `ThreadStateException` 被静默吞掉 → 实际跑在 MTA，WinForms 控件在 MTA 下行为异常（悬停消失是其表现之一）。改为用 `System.Threading.Thread` 显式在 `Start()` 前设 STA（`IsBackground=True`），并加兜底：STA 创建失败退回普通线程，保证托盘至少出现（不强引用保活已保留）。
